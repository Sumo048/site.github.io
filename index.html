My bets

01

Sim is cheap coverage.

Simulation is a great source of cheap data for robotics, and it can give policies the state and action coverage that real data alone can't.

02

Deploy fast, learn on the job.

Get policies into the real world as fast as possible, then improve them from robots actually doing (or trying to do) the tasks where they'll be useful.

What I'm working on now

Sim midtraining

Making cheap simulation data useful for pretrained robot policies.

Learning from deployment

Helping deployed robots unlearn failures nobody predicted.
